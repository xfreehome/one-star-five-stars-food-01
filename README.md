Entry for the [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7) bounty on [make.fun](https://make.fun): a program that writes one sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food.

## The entry

> One star: your gravity stole my luggage, your rain arrived unannounced, yet the tacos apologised for everything and I would cross three galaxies for seconds.

## Run

```sh
node main.ts   # writes /output/entry.txt (157 characters)
```

Requires Node 22.18+ (TypeScript runs as-is).
